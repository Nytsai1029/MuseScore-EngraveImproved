# MuseScore Engrave Improved Beta

MuseScore Engrave Improved is now available as a beta build for users who need more control over engraving
details than a standard score editor usually exposes.

## What Is New

- More flexible note placement for manual engraving adjustments.
- Editable ledger line length and behavior.
- Improved horizontal spacing with fewer avoidable collisions.
- Custom beam and beam-slant controls.
- Adjustable key signature spacing.
- Editable text letter spacing.
- Longer and draggable laissez vibrer lines.
- Broken and shaped ottava/slur-style line workflows.
- Editable hand-symbol appearance.
- PDF export now preserves italic and bold-italic text styling when fallback fonts are used.

## File Compatibility

Scores edited in this fork use the `.msdz` suffix so they can be kept separate from regular MuseScore Studio
files. Keep a backup copy of important work before moving a production score into the beta workflow.

## Recommended Use

Use this beta for engraving experiments, final-layout checks, and PDF export validation. Before sharing a score
publicly, review the generated PDF and confirm that text styles, spacing, and line shapes match the editor view.

## Feedback

Please report reproducible issues with a small score file, the expected result, the actual result, and the export
format involved.
